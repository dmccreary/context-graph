# Nexus Mascot Style Guide

This page shows all mascot admonition styles for **Nexus the Spider**,
the pedagogical agent for this textbook. Use it to verify that images load
correctly and that all seven admonition variants render as expected.

---

!!! mascot-neutral "A Note from Nexus"
    <img src="../../img/mascot/neutral.png" class="mascot-admonition-img" alt="Nexus neutral pose">
    This is the **neutral** style — used for general sidebars, introductions,
    or any content that doesn't call for a specific emotional tone.

!!! mascot-welcome "Welcome!"
    <img src="../../img/mascot/welcome.png" class="mascot-admonition-img" alt="Nexus waving welcome">
    This is the **welcome** style — used at the opening of every chapter to
    orient graph builders and set the stage for what's ahead.

!!! mascot-thinking "Key Insight"
    <img src="../../img/mascot/thinking.png" class="mascot-admonition-img" alt="Nexus thinking">
    This is the **thinking** style — used to highlight key concepts and
    pivotal ideas worth pausing on. Every node tells a story.

!!! mascot-tip "Nexus's Tip"
    <img src="../../img/mascot/tip.png" class="mascot-admonition-img" alt="Nexus giving a tip">
    This is the **tip** style — used for practical hints and helpful guidance
    that save context architects time in the field.

!!! mascot-warning "Watch Out!"
    <img src="../../img/mascot/warning.png" class="mascot-admonition-img" alt="Nexus warning">
    This is the **warning** style — used to flag common mistakes and pitfalls
    in graph modeling and LLM integration work.

!!! mascot-encourage "You Can Do This!"
    <img src="../../img/mascot/encouraging.png" class="mascot-admonition-img" alt="Nexus encouraging">
    This is the **encouraging** style — used when the material gets dense.
    Context graphs are complex; working through that complexity is exactly
    what builds durable expertise.

!!! mascot-celebration "Great Progress!"
    <img src="../../img/mascot/celebration.png" class="mascot-admonition-img" alt="Nexus celebrating">
    This is the **celebration** style — used at the end of major sections and
    chapters. Let's trace the why — and celebrate when we find it!

---
